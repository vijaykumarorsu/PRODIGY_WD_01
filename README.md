# PRODIGY_WD_01
# 🖥️ Navigation Bar Project

## 📌 Overview
This project demonstrates the creation of a **responsive navigation bar** using **HTML & CSS**. It includes a **fixed, sticky, and dropdown menu** for better user experience.

## 🚀 Features
- Responsive design for different screen sizes.
- Fixed and sticky navigation bar.
- Dropdown menu for better navigation.
- Simple and clean UI.

## 🔧 Technologies Used
- HTML5
- CSS3
